첫 번째 레벨: 황혼의 사냥터
2026-09-14

1. 이번 레벨의 범위
튜토리얼에서 마련한 조작·쿼터뷰·한글·렌더러를 바탕으로 만든 반복 사냥 구간이다.
보스나 퀘스트를 추가하지 않고 공격, 아이템 획득, 경험치, 자동 스탯 성장을 구현한다.
프로젝트 전체의 보스와 탐험 성장 방향은 유지하며 이 지역은 기본 RPG 시스템 검증용이다.
기본 실행 화면은 첫 레벨이고, 기존 튜토리얼 코드는 유지한다.
첫 레벨은 반복 성장용이므로 튜토리얼의 5분 완료 제한을 적용하지 않는다.

2. 조작
WASD: 화면 방향 기준 이동.
스페이스: 마나를 소비해 마법탄 발사. 가까운 시야 내 적을 자동 조준한다.
E: 1.5타일 안의 전리품 획득. 벽 너머 전리품은 획득하지 않는다.
Q: 회복 물약 사용. 최대 체력의 45%를 회복한다.
ESC: 메뉴 및 일시 정지.
메뉴에서 R: 랜덤 맵 재생성. 누적 경험치와 소지품은 유지한다.
F1: 기존 튜토리얼, F2: 첫 사냥터. 전환 후 ESC로 재개한다.
창 닫기: 저장 후 종료.

3. 경험치와 스탯
시작 레벨 1, 최대 레벨 30.
다음 레벨 필요 경험치 = 40 + (현재 레벨 - 1) × 20.
예: 누적 40 / 100 / 180 / 280 경험치에서 레벨 2 / 3 / 4 / 5.
한 번에 큰 보상을 받아 여러 레벨이 오르는 경우도 처리한다.
누적 경험치는 최대 1,000,000,000으로 제한한다.

최대 체력 = 60 + (레벨 - 1) × 12.
최대 마나 = 30 + (레벨 - 1) × 5.
공격력 = 10 + (레벨 - 1) × 3.
방어력 = 1 + (레벨 - 1).
레벨 상승 시 체력과 마나를 모두 회복한다.
공격력은 발사 시 마법탄 피해량에 적용된다.
받는 피해 = 최대(1, 적 공격력 - 플레이어 방어력).
스탯은 저장된 별도 수치가 아니라 누적 경험치에서 다시 계산한다.
레벨별 스킬 포인트나 장비 시스템은 이번 단계에 포함하지 않는다.

4. 전투와 아이템
마법탄: 공격 간격 0.5초, 마나 4 소비, 초당 9타일 이동.
나무·바위·물에 막히며, 이동을 잘게 나눠 고속 충돌 누락을 줄인다.
자동 조준 범위 7타일. 시야가 막힌 적은 자동 조준하지 않는다.
마나 자동 회복: 초당 6.
캠프 안전 영역: 반경 4타일, 초당 체력 10 회복.

몬스터 두 종류, 최대 24마리.
몬스터 레벨 1~3은 캠프와 생성 위치의 거리에 따라 정해진다.
체력 = 18 + 몬스터 레벨 × 6.
공격력 = 4 + 몬스터 레벨 × 2.
경험치 = 12 + 몬스터 레벨 × 6.
플레이어와의 길찾기 거리가 12칸 미만이면 추적하고, 그 외에는 순찰한다.
캠프 안전 영역 안으로 진입하지 않는다.
사망 10초 후 원래 위치에서 재생성하되, 플레이어가 4타일 이내에 있으면 기다린다.
플레이어 사망 시 캠프에서 회복하며 경험치와 소지품을 잃지 않는다.

몬스터 전리품:
- 골드: 2 + 몬스터 레벨.
- 추가로 물약 1개 또는 마력석 1개.
- 마력석 획득 시 마나 8 회복, 획득 개수도 소지품에 기록.
소지 제한: 골드·마력석 각각 1,000,000, 물약 99.
바닥 전리품은 성능을 위해 최대 300묶음으로 제한하며, 가득 차면 추가 드롭하지 않는다.
바닥 전리품은 저장하지 않는다. 획득한 소지품만 저장한다.

5. 랜덤 맵과 이동 보장
60×48타일 맵을 실행 및 메뉴 R 입력 시 새 시드로 생성한다.
바다·맵 외곽은 명시적인 비이동 지형이며 나무·바위는 장애물이다.
나머지 이동 가능 땅은 전부 하나의 연결된 영역이 되도록 구성한다.
생성 후 캠프에서 BFS로 도달 가능 영역을 검사한다.
분리된 땅은 캠프까지 가로·세로 통로를 뚫어 연결한다.
통로 생성은 장애물을 제거하는 방향으로만 동작하므로 기존 연결이 끊어지지 않는다.
최종 검사에 실패하면 내부 이동 구역을 여는 안전 대안을 적용한다.
플레이어 반경을 반영한 충돌 검사로 한 칸짜리 통로도 실제 통과 가능하게 한다.
캠프 소품은 장식이며 연결 검사를 무효화하는 별도 충돌을 추가하지 않는다.
몬스터는 연결된 땅에서 충분히 떨어진 위치를 선택하고 전리품은 그 처치 위치에 놓는다.
몬스터 추적은 플레이어 기준 거리 지도를 약 0.25초 간격으로 갱신해 사용한다.
지도 시드는 UI에서 확인할 수 있다.

6. 모델 파일 캐시
사냥터 모델은 원·타원·삼각형·사각형으로 만든 색상 정점 데이터다.
마법사 대기·걷기 4프레임·시전, 몬스터별 4프레임, 나무·바위·오두막·모닥불,
골드·물약·마력석·그림자를 총 22개 모델로 저장한다.
첫 실행에 파일이 없으면 모델을 만들고 저장한다.
다음 실행에서는 유효한 파일을 읽으며 모델 생성 함수를 실행하지 않는다.
형식 서명, 정점 수, 좌표·색상 범위와 체크섬을 검사한다.
캐시가 손상되거나 버전이 맞지 않을 때만 재생성한다.
쓰기 실패 시 이번 실행은 메모리 모델로 계속하되 HUD에 실패를 표시한다.
캐시 상태(파일 로딩 / 최초 생성 및 저장 / 저장 실패)는 화면 하단에서 확인한다.
GPU 객체는 실행 때 다시 업로드한다. 캐시 대상은 재사용 가능한 모델 정점과 애니메이션 프레임이다.
지도 배치와 UI는 실행 상태에 맞춰 구성한다. 기존 튜토리얼 도형은 기존 방식으로 유지한다.

7. 셰이더
Effect.vs / Effect.fs:
- 물 타일의 파동·잔물결.
- 모닥불의 흔들림과 중심부 밝기.
- 마법탄과 시전 구체의 빛·고리.
CPU는 위치와 시간을 전달하고 효과의 모양 변화는 셰이더에서 계산한다.
기존 후처리와 한글 UI 렌더링을 유지한다.

8. 저장 위치와 정책
Windows 사용자 폴더 %LOCALAPPDATA%\Emberwick 아래:
- primitive_models_v3.bin: 재사용 모델 캐시.
- level1_progress.txt: 누적 경험치, 골드, 물약, 마력석.
프로그램 실행 위치나 디버거 작업 폴더가 달라도 같은 사용자 데이터를 읽는다.
임시 파일을 완전히 쓴 후 원래 파일을 교체한다.
경험치 획득·아이템 획득·물약 사용·일시 정지·종료 시 성장 데이터를 저장한다.
잘못된 저장 형식·범위 값은 적용하지 않고 기본 성장 데이터로 시작한다.
체력·마나·지도·몬스터·바닥 전리품은 실행 간 저장하지 않는다.
다음 실행에서는 경험치와 소지품을 복원하고 체력·마나는 가득 채워 새 지도로 시작한다.
지도 재생성은 성장 데이터를 초기화하지 않는다.

9. 코드 구성
LevelOne.cpp / .h: 첫 사냥 레벨, 전투·아이템·화면·입력 연결.
HuntingMap.cpp / .h: 랜덤 생성, 이동 충돌, 연결 검사와 거리 지도.
RpgProgress.cpp / .h: 경험치, 스탯 계산과 성장 저장.
PrimitiveModels.cpp / .h: 도형 모델·애니메이션 프레임 생성 및 파일 캐시.
RuntimeFiles.cpp / .h: 사용자 데이터 경로 및 파일 교체.
Renderer.cpp / .h: 캐시 모델 그리기와 효과 셰이더 API 추가.
SimpleGame.cpp: 첫 레벨 기본 진입과 F1/F2 화면 선택.
모든 신규 C++ 코드는 .clang-format을 적용한다.

10. 검증 및 수동 확인
이번 작업에서 게임을 빌드하거나 실행하지 않았다.
프로젝트 파일 참조, 코드 포맷, 변경 사항은 정적으로 확인한다.

Visual Studio에서 다시 빌드한 뒤 확인:
1) 기본 화면이 첫 사냥터인지, 모든 안내가 한글인지.
2) 첫 실행에서 모델 생성·저장, 다음 실행에서 파일 캐시 로딩으로 표시되는지.
3) 몬스터에게 마법탄이 맞으면 체력 감소·처치·경험치가 한 번씩 발생하는지.
4) 나무·바위 너머 적에게 탄이 통과하지 않는지.
5) E로 전리품 획득, Q로 물약 사용과 소지 수량 감소가 반영되는지.
6) 누적 경험치 40·100·180에서 레벨과 실제 스탯이 상승하는지.
7) 메뉴 R을 여러 번 실행해 막힌 이동 구역이나 갇힌 스폰이 없는지.
8) 몬스터 재생성·추적과 캠프 안전·회복, 사망 복귀가 동작하는지.
9) 불꽃·물결이 움직이고 창 크기 변경 뒤에도 화면이 정상인지.
10) 종료 후 다시 실행해 경험치·소지품 유지와 새 지도 생성을 확인.
11) F1/F2 전환과 ESC 재개 때 키가 눌린 상태로 남지 않는지.

선택적 로직 검사 코드: tests/LevelOneLogicTests.cpp.
256개 시드의 지도 연결·이동 반경, 경험치 경계와 여러 레벨 상승을 검사한다.
게임 프로젝트에는 포함하지 않으며 아직 빌드·실행하지 않았다.
Visual Studio 개발자 명령 프롬프트에서 별도 실행 파일로 빌드할 수 있다:
cl /EHsc /utf-8 tests\LevelOneLogicTests.cpp SimpleGame\HuntingMap.cpp SimpleGame\RpgProgress.cpp SimpleGame\RuntimeFiles.cpp /Fe:LevelOneLogicTests.exe
