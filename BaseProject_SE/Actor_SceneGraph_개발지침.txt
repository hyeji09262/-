Actor / SceneGraph 및 모델 디테일 개선 — 2026-09-21

1. 목적
월드에 배치한 캐릭터·지형·소품·효과의 렌더링 진입점을 Actor로 통일한다.
기존 전투·이동·아이템·성장·퀘스트 로직은 각 레벨에 유지한다.
이번 변경은 별도 엔진 교체나 전투 ECS 전환이 아니라 배치 및 렌더링 계층의 분리다.

2. 파일 역할
SimpleGame/Actor.h: 이름, 로컬 위치(x,y,z), 크기, 부모/자식, 활성/표시 여부, 그리기 콜백.
SimpleGame/SceneGraph.h: Actor 소유권, 이름 검색, 생성·연결·제거, 부모 변환 상속,
배경/지면/그림자/월드/오버레이/UI 레이어 및 월드 바닥 깊이 정렬.
SimpleGame/CharacterVisual.h: 캐릭터 자세와 마법봉 소켓의 공유 좌표.
SimpleGame/LevelOne.cpp 및 TutorialArt.h: 게임 상태를 Actor 배치에 반영하는 어댑터.

3. 계층 예시
terrain → 지면/물 타일
scenery → 학교, 나무, 돌, 회복 거점 → 그림자/불꽃
characters → player → body(첫 레벨), shadow, wand → flash(첫 레벨)
characters → enemy / npc / boss → shadow / warning
loot / spells / effects → 전리품, 투사체, 파티클
ui → HUD 합성 오브젝트 (텍스트 글자와 패널의 삼각형까지 개별 Actor로 만들지는 않음)

4. 사용 규칙
BeginSync → Place로 배치 동기화 → EndSync → Render 순서로 사용한다.
Place는 동일 이름의 Actor를 재사용하며 게임 상태에서 local과 콜백을 갱신한다.
enabled/visible은 동기화 때 초기화하지 않으며 부모의 숨김/비활성은 자식에도 적용된다.
동기화에서 제외된 Actor는 EndSync에서 제거된다. 부모를 배치할 때 자식보다 먼저 등록한다.
이름은 그래프 내부에서 고유해야 한다. 첫 레벨 투사체와 전리품은 별도의 고유 ID를 사용한다.
부모 제거 시 자식도 제거한다. 순환 연결과 다른 그래프 Actor 연결은 거부한다.
부모 변경은 로컬 좌표를 유지하므로 월드 좌표는 새 부모에 맞춰 달라진다.
현재 변환은 이동·높이·균일 크기를 지원하며 회전은 포함하지 않는다.
그리기 콜백 실행 중 그래프를 추가·삭제하지 않는다. 포인터는 제거 또는 Clear 이후 사용하지 않는다.
충돌 지도와 경험치 상태는 Actor 변환으로 자동 변경되지 않는다.
게임 오브젝트의 실제 이동은 기존 게임 상태를 수정한 뒤 장면 동기화로 반영한다.
HUD는 화면 공간에 유지하며 게임 월드의 후처리 밖에서 렌더링한다.

5. 마법 출발점
시전 자세의 지팡이 별 중심 (20, -66)을 쿼터뷰 월드 소켓으로 변환한다.
왼쪽을 향할 때 소켓도 좌우 반전한다. 시전 중에는 시전 방향을 고정한다.
튜토리얼 광선은 player/wand Actor의 월드 좌표에서 시작한다.
첫 레벨은 기존 충돌 궤적·사거리·피해량을 보존한다. 시각적인 투사체 시작 위치는
발사 순간 지팡이 소켓에서 출발해 0.18초 동안 기존 투사체 높이/궤적으로 자연스럽게 합류한다.
따라서 벽 뒤에서 발사하는 별도 공격 판정이나 사거리 증가를 추가하지 않는다.

6. 모델
캐릭터: 머리카락 하이라이트, 눈 반사광, 볼, 칼라, 주름·레이스, 부츠 테두리, 별 지팡이.
나무: 뿌리·갈라지는 가지, 꽃송이 층, 꽃 하이라이트, 바닥 꽃잎.
돌: 밝고 어두운 면, 균열, 이끼, 주변 작은 돌.
학교: 창문 반사광·창턱과 입구 계단.
캐시는 primitive_models_v5.bin으로 분리한다. 기존 성장 저장 파일은 변경하지 않는다.

7. 검증
요청에 따라 빌드·실행 및 테스트 실행은 하지 않았다.
tests/SceneGraphTests.cpp는 별도 콘솔 테스트용이며 게임 프로젝트에 main으로 추가하지 않는다.
부모 변환, 표시 상속, 순환 방지, 동일 Actor 재사용, 깊이/레이어 순서, 하위 제거,
좌우·대기·시전 소켓 좌표에 대한 회귀 테스트를 포함한다.
사용자 확인: F1/F2 전환, 양방향 이동/시전, 발사 중 이동, 나무 뒤 가림,
드롭 획득/적 부활/새 맵 생성 후 잔상, 물/불꽃, UI, 재실행 캐시 로딩.
