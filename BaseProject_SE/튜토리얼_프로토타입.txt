잔불 마을: 마지막 온기 — 튜토리얼 프로토타입
개선판 0.2 / 2026-09-09

1. 목표
싱글플레이 2.5D 쿼터뷰 RPG의 보스 → 스킬 → 탐험 → 보상 순환을 경험한다.
핵심 동선은 2~4분, 첫 플레이 5분 이내를 설계 목표로 유지한다.
확장 지역은 선택 탐험 공간이다. 실제 플레이 시간은 사용자가 확인해야 한다.
게임 시간은 일시 정지·스킬 선택 중 멈춘다. 5분 강제 종료는 없다.

2. 이번 개선
- 전체 맵 30×24 → 60×48타일: 가로·세로 두 배, 면적 네 배.
- 육지 폭 22 → 44타일, 전체 세로 24 → 48타일.
- 주민 7 → 14명: 각자 한글 이름과 대사.
- 야생 몬스터 두 종류, 총 12마리: 이끼 덩어리와 그림자 들짐승 형태.
- 한글 UI·대사·창 제목. 키 이름과 API 진단 원문은 고유 표기를 유지.
- GDI의 맑은 고딕을 글리프 텍스처 아틀라스로 만들어 한글을 표시.
- 월드를 FBO에 그린 뒤 밝은 영역의 블룸, 황혼 색보정, 비네트와 미세 입자감을 적용.
- 후처리 뒤 UI를 별도로 그려 글자가 흐려지지 않게 처리.
- 지면 접촉 그림자와 여러 겹의 부드러운 투영 그림자를 모든 오브젝트보다 먼저 렌더링.
- 캐릭터 부츠·다리·소매·손·벨트·얼굴·모자·지팡이를 분리하고 보행·호흡·시전 동작 추가.
- 목조·석조 벽, 지붕의 기와·초가 무늬, 문·창살·굴뚝 연기 추가.
- 우물, 수레, 상자, 통, 가로등, 바위, 풀과 작은 꽃 추가.
- 길의 돌 조각과 이동 먼지, 해안 포말과 잔물결, 나무 흔들림 추가.
- 마법 광선의 겹친 빛, 시전·명중·피격·처치·보상 입자 추가.
- 미니맵에 길·바다·주민·몬스터·플레이어·목표 표시.
- 삼각형 배치 렌더링으로 도형별 버퍼 업로드와 그리기 호출을 줄임.

3. 조작
WASD: 화면 방향 기준 이동. 대각선 속도 정규화.
E: 주민 대화, 의뢰 수락·완료, 해안 제단 상호작용.
스페이스 유지: 6.5타일 내 가장 가까운 살아 있는 적에게 마법 공격.
적이 없어도 시전 효과는 나타나지만 피해는 발생하지 않는다.
1 / 2: 보스 처치 후 스킬 강화 선택.
ESC: 일시 정지·재개.
R: 완료 화면에서 다시 시작.
창 닫기: 종료.

4. 퀘스트와 위치
출발: (31,26), 마을 광장.
촌장: (32,24). E로 '마을의 마지막 온기' 의뢰를 수락한다.
보스: (30,16), 마을 북쪽 숲의 공터.
보스 처치 뒤 그림자 봉인 해제를 기본 습득하고 강화 하나를 선택한다.
  1. 먼 손길: 제단 상호작용 거리 2.1 → 4타일.
  2. 가벼운 발: 초당 이동 거리 3.5 → 4.5타일.
해안 제단: (43,26). E로 새벽 불씨를 획득한다.
촌장에게 돌아와 E를 눌러 완료한다.
최초 경로와 핵심 구간 거리는 이전 버전과 비슷하게 유지했다.
미니맵과 금색 표시로 목적지를 찾을 수 있다.

5. 주민
촌장 모라, 제빵사 보리, 어부 해솔, 견습생 루아, 묘지기 무영,
경비병 단, 약초상 연두, 대장장이 철수, 등대지기 나루, 목수 다온,
행상인 모루, 아이 별, 양조사 담, 수녀 은.
주민은 고정 배치이고 호흡 애니메이션만 적용한다. 보행 AI는 아직 없다.

6. 야생 전투
야생 몬스터는 주변을 순찰하다가 5.5타일 내 플레이어를 발견하면 추적한다.
스폰 지점에서 8타일 이상 벗어난 플레이어는 추적하지 않고 돌아간다.
지형·건물 충돌을 적용하며 광장 안전 영역으로 진입하지 않는다.
0.9타일 내 접촉 시 공격하고 개별 공격 대기 시간은 1.8초다.
야생 몬스터 체력 3. 처치 시 체력 1을 회복하고 처치 수를 표시한다.
이번 프로토타입에는 야생 몬스터 자동 재생성이 없다.
광장 중심 6타일 이내에서 2초마다 체력을 1 회복한다.

7. 보스와 실패 처리
보스 체력 10, 플레이어 체력 5.
보스는 3.2초마다 공격하며 마지막 1.1초를 강한 붉은색으로 예고한다.
3타일 피해 반경을 월드 좌표에서 원으로 만들어 화면에 투영한다.
플레이어는 0.5초 간격으로 공격하고 피격 후 1.2초 동안 추가 피해를 받지 않는다.
사망하면 마을로 돌아가 체력을 회복하고 보스 체력은 초기화된다.
퀘스트·이미 처치한 야생 몬스터 상태는 유지하며 살아 있는 몬스터는 원위치로 돌아간다.
보스·제단 보상은 퀘스트 단계로 중복 지급을 막는다.

8. 파일과 기술
Renderer.cpp / Renderer.h: 배치 도형, 한글 글꼴 아틀라스, FBO와 후처리.
Tutorial.h: 월드 데이터, 주민·몬스터, 입력, 전투, 퀘스트, UI.
TutorialArt.h: 건물·환경·캐릭터·몬스터 표현과 미니맵.
SolidRect.vs / SolidRect.fs: 정점 색상과 글리프 텍스처 렌더링.
Screen.vs / Post.fs: 전체 화면 후처리.
SimpleGame.cpp: 기존 창·입력·타이머 루프 유지.
Visual Studio 프로젝트·필터에 새 헤더와 셰이더를 등록했다.
전 구성에 /utf-8 옵션을 추가했고, 빌드 후 Shaders를 출력 폴더에 복사한다.
기존 C++ / OpenGL / FreeGLUT / GLEW를 계속 사용한다.

9. 표현상의 범위
그림자는 2D 지면에 투영한 부드러운 근사 그림자다. 3D 그림자 맵은 아니다.
벽·지붕 재질은 코드로 그린 무늬다. 외부 PBR 텍스처를 도입하지 않았다.
캐릭터는 부위별 도형 애니메이션이다. 스프라이트 시트 애니메이션은 아직 없다.
후처리 블룸은 단일 패스의 저비용 밝은 영역 블러다.
전투는 자동 조준 즉시 피해이며 투사체 물리·장애물 차폐 판정은 아직 없다.
몬스터는 단순 추적·충돌 회피 이동을 사용하며 복잡한 경로 탐색은 없다.
맵 저장, 청크 스트리밍, 인벤토리와 완성형 사운드는 이번 범위에 없다.

10. 사용자가 확인할 항목
이 개선에서는 Codex가 빌드나 실행을 하지 않았다.
프로젝트 XML과 변경 내용은 정적으로 확인했다. 아래 항목은 직접 확인해야 한다.

1) Visual Studio에서 솔루션 다시 빌드: 글자 인코딩 옵션과 셰이더 인터페이스가 바뀌었다.
2) 실행 폴더 Shaders에 SolidRect 두 파일, Screen.vs와 Post.fs가 복사됐는지 확인.
3) 첫 화면부터 한글 제목·주민 대사·메뉴가 깨지지 않는지 확인.
4) 창 크기를 변경해도 후처리와 한글이 정상인지 확인.
5) 후처리 밝기, 그림자, 건물·물·마법 효과가 과하지 않은지 확인.
6) 걷기·정지·시전 시 캐릭터 부위가 자연스럽게 움직이는지 확인.
7) 주민 14명과 확장 지도·해안 경계·주변 숲을 확인.
8) 야생 몬스터의 순찰·추적·접촉 공격·사망, 광장 안전과 회복을 확인.
9) 야생 몬스터와 보스가 가까울 때 가장 가까운 적을 공격하는지 확인.
10) 보스 전조와 실제 피해 범위, 사망 복귀를 확인.
11) 스킬 선택 두 가지와 제단·촌장 귀환 퀘스트를 각각 완료.
12) 첫 플레이 시간을 벽시계로 재어 5분 이내 핵심 동선인지 확인.
13) 완료 후 R을 눌러 주민·몬스터·보상·시간·체력이 초기화되는지 확인.
