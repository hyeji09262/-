스토리 중심 마을 정리

- 별도 튜토리얼 장면 진입을 제거했습니다. F1과 F6은 동일한 스토리 마을입니다.
- 시작은 기존 프롤로그의 집입니다. 집에서 나가면 마을의 실제 집 입구로 연결됩니다.
- 별빛 학교 입구에서 E를 누르면 현재 이야기를 이어갑니다.
- 메인퀘스트1 보상/후일담 완료 후 학교 진입은 메인퀘스트2로 연결됩니다.
- 기존 스토리 전용 장면과 저장 데이터는 유지했습니다. 모든 스토리 장면을 하나의
  연속 지형으로 합친 것은 아니며, 학교 출입 시 해당 장면으로 전환합니다.
- 다른 두 마을은 메인퀘스트1 후일담/보상 완료 후 개방됩니다.
- F2 사냥터, F3 이야기, F4 퀘스트2 바로가기는 확인용으로 유지합니다.

배치
- 주거/학교, 생활 시설, 교통/상업 구역으로 세로 간격을 약 13~14 월드 단위로 확대.
- 우리 집, 학교, 편의점, 병원, 쇼핑몰, 지하철역, 중앙공원으로 시설 역할을 구분.
- 병원은 회복, 쇼핑몰과 지하철은 후속 퀘스트용 안내 공간입니다.
- 지하철 운행과 신규 시설 퀘스트 자체는 아직 구현하지 않았습니다.
- 중앙공원은 지붕 없는 나무/벤치 공간이며 통행을 막지 않습니다.
- 병원은 민트 의료 표식, 쇼핑몰은 넓은 외형과 보라 간판,
  역은 낮은 외형과 파란 간판으로 구분합니다. 외벽/지붕 색도 다르게 적용했습니다.

확인
- 리소스 검증, C++ 문법 검사, 실제 메시 기반 입구 연결 CPU 테스트 수행.
- 게임 빌드 및 실행은 사용자 확인: 집 → 학교 E → 현재 퀘스트 연결,
  병원 회복, 공원 통행, 쇼핑몰/역 출입과 이름표 표시 확인.
