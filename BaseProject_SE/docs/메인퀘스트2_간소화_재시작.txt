메인퀘스트 2 최신 흐름

1. 1학년 1반 창문 밖으로 몬스터가 지나간다. '연출 중' 안내 후 E로 조사를 시작한다.
2. 복도 사물함, 도서관 대출 기록, 방송실 녹음 장비를 순서에 상관없이 조사한다.
3. 조사를 모두 마치면 노란 목표가 체육관 문을 안내한다.
4. 체육관 입구 흔적을 E로 확인하면 3초 변신 모션 후 강화 그림자 전투가 시작된다.
5. 처치 즉시 학교 사건이 끝나고 보상을 받는다. 완료 대화에서 E로 마을에 돌아간다.

이번 버전의 제외 항목
- 조사 전 변신 및 복도 전투. 변신은 체육관 보스전 직전에만 진행한다.
- 체육 창고 봉인, 별도 조각 획득/보고 단계, 창고 추가 보상.
- 학교 선생님 4명의 배치, 대사와 모니터 상태.
프롤로그의 첫 변신과 사냥터는 유지한다.

보상
- 최초 완료 시 경험치 180, 골드 150, 체력/마나 물약 각각 2개, 검은 조각 1개.
- 마력석과 회피는 다시 추가하지 않는다.
- 이야기 재시작 때 성장과 소지품은 유지한다. 이미 받은 완료 보상은 중복 지급하지 않는다.

처음부터 다시 보기
- F4 메인퀘스트 2 화면 오른쪽 위 '처음부터 [B]' 버튼을 클릭한다.
- B키로도 동일하게 다시 시작한다. ESC 메뉴나 완료 상태에서도 가능하다.
- 현재 저장을 날짜/시각이 붙은 .restart-*.bak 파일로 백업한 뒤 조사 진행만 초기화한다.
- 백업에 실패하면 현재 진행을 초기화하지 않는다.
- 창문 연출과 조사 0/3부터 다시 진행하며 다른 퀘스트/사냥터 저장은 변경하지 않는다.

저장 호환
- main_quest_002.txt를 V2 형식으로 저장하며 완료 보상 지급 여부를 별도로 기록한다.
- 기존 V1 파일은 .before_v2.bak으로 보존한 뒤 읽는다.
- 기존 복도 전투 단계는 체육관 이동 단계로 연결한다.
- 기존 조각 획득/보고 단계는 새 체육관 전투로 연결한다.
- 기존 완료는 완료로 유지하므로 새 구성을 보려면 '처음부터 [B]'를 사용한다.

검증
- 변경 C++ 문법 검사 통과. 게임 빌드/실행은 하지 않았다.
- 6가지 조사 순서 → 체육관 → 전투 → 완료 진행과 중복 조사 차단 검사 통과.
- 재시작 후 조사 초기화, 성장/소지품 유지, 완료 보상 중복 지급 방지 검사 통과.
- 수동 확인: 버튼 클릭/B키, 저장 백업 생성, 재실행 후 이어하기, 창문 연출,
  학교 조사와 체육관 Q 전투, 완료 E 마을 귀환을 확인한다.
