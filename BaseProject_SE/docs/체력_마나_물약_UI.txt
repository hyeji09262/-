최신 체력/마나 UI 및 조작 (이전 R 보충 안내보다 우선)

튜토리얼, 사냥터, 스토리의 체력/마나를 왼쪽에 세로 기둥 두 개로 나란히 배치한다.
막대는 아래에서 위로 차오르며, 기준 화면에서 폭 22 / 높이 280으로 표시한다.
두 막대의 시작 x는 48과 112이며, 왼쪽 패널 범위는 x=22~174, y=212~566이다.
스토리 대화창은 x=200부터 배치하여 막대 패널을 가리지 않는다.
각 기둥 아래에 수치와 물약 키/개수를 표시한다.
큰 숫자와 굵은 막대를 사용하며 체력은 분홍색, 마나는 파란색이다.
Z: 기존 체력 물약 사용. X: 마나 물약 1개 소비 후 즉시 최대 마나 회복.
마나가 가득 차거나 물약이 없으면 소비하지 않는다. R 보충 입력은 제거했다.
마나 물약은 기본 3개이며 사냥터/스토리 저장에 남은 수량을 보관한다.
이전 저장 파일은 최초 전환 시 마나 물약 3개로 읽는다. 튜토리얼은 재시작 시 초기화된다.
사냥터 몬스터는 골드와 함께 체력 물약/마력석/마나 물약 중 하나를 같은 확률로 드롭한다.
마나 물약은 파란 이름표로 구분하며 E로 획득, X로 사용한다. 최대 99개 소지 가능하다.
99개일 때는 마나 물약을 바닥에 남긴다. 획득한 수량은 기존 자동 저장에 포함된다.
상점은 아직 구현하지 않았다.

사용자 확인: 세 장면에서 왼쪽 막대 가독성, Q 마나 감소, X 즉시 회복/수량 감소,
만충/0개/사망/대화/일시정지 시 소비 방지, 저장 후 재실행 시 수량 유지 확인.
빌드/게임 실행은 진행하지 않았다. 새 저장은 구버전 실행 파일에서 읽을 수 없다.
