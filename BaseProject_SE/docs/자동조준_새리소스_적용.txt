자동 조준 및 새 리소스 적용

기존 '학교_리소스_방향_업데이트.txt'의 자동 조준 제거 설명은 이번 변경으로 대체됩니다.

전투
- Q를 누르고 있으면 공격 간격에 맞춰 가까운 살아 있는 적을 자동 조준합니다.
- 사냥터에서는 기존 시야 판정을 유지합니다. 적이 없으면 마지막 방향으로 발사합니다.
- 조준 방향과 공격 자세를 일치시키고 마법봉 끝 소켓에서 마법이 출발합니다.
- 마나 소비와 Z 체력 물약 / X 마나 물약 등 기존 조작은 유지합니다.

리소스
- resource/assets의 새 Blender 라이브러리를 읽어 런타임 메시를 다시 생성했습니다.
- 원본 Blender 파일은 수정하지 않았습니다.
- 캐릭터, 몬스터, 학교/주택/상점 조립본, 가구, 나무/바위/풀 변형을 사용합니다.
- 전용 모델이 없는 일부 소품은 제공된 메시를 조합한 근사 표현입니다.
- 건물은 실제 모델 크기에 맞는 충돌 범위, 계단 앞 입구와 이름표 높이를 사용합니다.
- 입구 연결 길과 화단을 배치하고 나무/바위/풀 모양을 다양화했습니다.
- 배치 객체는 기존 Actor / SceneGraph 경로를 유지합니다.
- 탐험, NPC 상호작용, 전투와 기존 퀘스트 진행 구조는 유지합니다.

변환 및 검사
- 변환: Blender 백그라운드에서 resource/export_runtime_models.py 실행.
- 출력: resource/runtime/school_models.bin 및 manifest.json.
- 형식 MGSRES03: 기본 메시 74개, 방향별 캐릭터 포즈 88개, 건물 배치 정보 포함.
- manifest에는 사용한 원본 31개의 SHA-256을 기록합니다.
- tools/validate_resource_models.py는 체크섬, 원본 해시, 정점과 메타데이터를 검사합니다.
- FacingAndSchoolTests: 자동 조준, 마법봉 소켓, 학교 내부 연결 검사.
- ResourceModelsTests: 실제 리소스 로딩과 건물/화단을 고려한 입구 연결 검사.
- 성능 개선 수치는 게임 실행 측정 전이므로 제시하지 않습니다.

사용자 실행 확인
1. Visual Studio에서 다시 빌드해 새 실행 파일과 리소스를 함께 갱신합니다.
2. F1/F2/F3/F4에서 Q를 누르고 적 자동 조준과 마법봉 출발 위치를 확인합니다.
3. F6에서 건물 계단 앞으로 이동해 E 출입, 이름표, 길과 화단을 확인합니다.
4. 학교 복도/교실 이동과 기존 퀘스트 및 저장 진행이 유지되는지 확인합니다.

게임 빌드 및 실행 검증은 사용자가 수행합니다.
