현재 적용된 공통 조작

Space: 점프 (변신 전후 동일, 회피 무적 없음)
Q: 기본 공격
R: 마법봉 재충전
Z: 물약
E: 상호작용/획득
WASD: 이동
ESC: 일시정지
F1: 기존 튜토리얼 / F2: 사냥 / F3: 프롤로그·메인 퀘스트 1
F4: 메인 퀘스트 2 (현재 준비 중 안내 화면) / F5: 성능 로그 켜기·끄기
처음부터: F3 전환 시 열린 메뉴에서 B → Enter. 플레이 중에는 ESC로 메뉴를 연다.
확인 화면의 ESC는 취소. 기존 N은 현재 단계 재도전을 유지한다.
새 시작 시 main_quest_001.txt를 같은 폴더의 고유 .backup_이름으로 옮긴 뒤 초기화한다.
백업 실패 시 진행을 유지한다. 사냥 레벨의 저장 데이터는 변경하지 않는다.

메인 스토리: Shift 달리기, 1 별빛 폭발, 2·3 이후 공격은 추가 예정.
기존 튜토리얼의 강화 선택 화면에서만 1·2는 기존 선택 기능을 유지한다.
기존 사냥의 새 맵은 메뉴에서 N, 튜토리얼 완료 후 재시작도 N이다.
X 특수 마법/J 점프의 이전 바인딩은 제거했다.

재충전은 6회분을 1.2초에 채우며, 진행 중 기본 공격을 막는다.
메인 스토리의 특수 마법도 재충전 중에는 사용할 수 없다.
마법봉 충전과 기존 MP는 별개이며 기존 MP 소비/자연 회복은 유지한다.
재충전 중 이동·점프·물약은 가능하다. 충전 수는 HUD에서 확인할 수 있다.
장면 전환/일시정지 시 재충전 시간은 진행하지 않는다.
체크포인트 재시도/새 게임 때 충전은 초기화하며 별도 저장하지 않는다.
튜토리얼의 물약은 실행 회차마다 3개, 1개당 체력 2/5를 회복한다.

수동 확인
- 세 장면 모두 Space로 점프만 하고 Q로 공격하는지.
- Q 6회 후 공격이 멈추고 R을 누른 뒤 1.2초 후 다시 가능한지.
- R 연타로 재충전이 빨라지거나 계속 초기화되지 않는지.
- 메인 스토리에서 변신 전 공격/재충전/특수 마법이 잠겨 있는지.
- 1번 마법, Z 물약, N 메뉴 기능과 기존 E 상호작용이 정상인지.
- 점프 중 마법봉/발사 효과가 캐릭터 높이를 따라가고 그림자는 바닥에 있는지.
- tests/PlayerActionsTests.cpp는 별도 CPU 테스트로 충전/점프 규칙을 확인한다.
이번 작업에서는 빌드·게임 실행·테스트 실행을 하지 않았다.
