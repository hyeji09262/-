학교 이야기 연결 수정

- 복도의 '현재 이야기 이어가기' 표식과 (2,8)의 전용 상호작용을 제거했다.
- 마을에서는 학교 입구, 복도에서는 실제 목표 방의 문을 노란색으로 안내한다.
- 목표 방으로 이동하면 해당 방 좌표를 유지하면서 메인퀘스트 2로 연결한다.
- 월드 학교와 퀘스트 학교가 각각 별개의 빈 체육관으로 보이지 않게 연결했다.
- F4 이어하기와 기존 저장 단계는 유지한다. 저장을 초기화하지 않는다.

장면과 진행
- 프롤로그 마지막 교실과 퀘스트 2 도입은 1학년 1반으로 맞췄다.
- 그림자가 지나가는 위치를 현재 교실의 창문 좌표에 맞추고, 창문 앞에 보이도록 했다.
- 마지막 교실 연출 중 E를 먼저 눌렀으면 연출이 끝난 뒤 다음 퀘스트로 연결한다.
- 세 번째 조사를 방 안에서 마치면 출입문으로 복도 복귀를 안내한다.
- 복도에 도착하면 회전·떠오르기·교복에서 마법소녀로 전환·빛 효과의 3초 변신을 재생한다.
- 변신 중 적과 입력을 멈추고, 연출 종료 후 Q 전투를 활성화한다.
- 체육관 단계는 실제 체육관 문으로 들어가 입구 흔적을 확인한 뒤 보스전으로 이어진다.

체육관 내부 좌표
- 입구 흔적 및 재시도 진입: (16,22).
- 검은 조각: (16,13).
- 보고 대상 루미: (5,21). 보급함: (5,23).
- 창고 봉인: (25,8). 보급품: (28,6).
- 창고에 벽과 낮은 앞벽, 보라색 봉인, 빛나는 표식을 배치했다.
- 봉인 근처에서 2를 사용한 뒤 실제 열린 출입구로 들어가 E로 보상을 얻는다.
- 목표, 렌더링, 충돌, 상호작용 좌표를 함께 변경했다.

검증
- 변경 C++ 문법 검사 및 퀘스트 진행·변신 타이밍 CPU 테스트 통과.
- 체육관 진입점에서 조각·루미·봉인 앞까지의 경로를 검사했다.
- 정화 전 보급품 접근 차단, 정화 후 보급품 접근 가능을 경로 탐색으로 확인했다.
- 게임 빌드와 실행 화면 확인은 하지 않았다.
- 수동 확인: 학교의 노란 목표 → 실제 방 진입 → 조사 → 복도 복귀 → 변신 → Q 전투,
  체육관 문 진입 → 보스 → 조각 → 루미 → 2 정화 → 창고 보급품 E 순서로 확인한다.
