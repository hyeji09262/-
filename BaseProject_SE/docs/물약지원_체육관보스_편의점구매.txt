물약 지원·체육관 보스·편의점 구매

프롤로그 지원
- 기본 체력/마나 물약은 각각 5개다.
- 프롤로그 퀘스트 시작, 저장 불러오기, 단계 전환, N 재시도 시 최소 5개까지 보충한다.
- 5개보다 많이 가진 수량은 줄이지 않는다. 이동 장면의 기본 보유량도 5개다.

플레이어 판정 조정
- 기본 투사체의 일반 몬스터 명중 반경을 이야기에서 0.6→0.85타일,
  사냥터에서 0.5→0.8타일로 늘렸다. 이야기 보스는 1→1.35타일이다.
- 사냥터 전리품 획득 거리는 1.5→2타일이다.
- 주요 조사/NPC 대화는 2.3타일, 문은 약 2타일 거리에서 상호작용할 수 있다.
- 60도 자동조준은 유지한다. 이야기에서는 벽 너머 몬스터를 조준 후보에서 제외한다.
- 적 공격의 명중 반경을 늘린 것은 아니다.

체육관 보스
- Gym_EnhancedShadow_Boss.blend의 Walk/Attack을 8방향으로 저장했다.
- 체육관 보스만 새 리소스를 사용하며 골목의 ShadowEater_Boss는 유지한다.
- 런타임 메시 수 1,435개 + 플레이어 방향별 포즈 88개, 파일 크기 100,422,556바이트.
- 새 리소스는 빌드 시 실행 폴더에 복사된다.

퀘스트 완료 후 구매
- 완료 대화와 마을 복귀 안내에서 편의점으로 유도한다.
- 첫 구매까지 월드/미니맵은 편의점 입구, 내부는 직원 계산대를 노란 목표로 표시한다.
- 계산대 앞 E: 구매 메뉴. 1: 체력 물약 20골드, 2: 마나 물약 25골드.
- E/ESC로 메뉴를 닫는다. 메뉴가 열린 동안 월드 이동/전투는 일시 정지한다.
- 한 번에 1개 구매하며 보유 한도 99개, 골드 부족 시 구매하지 않는다.
- 퀘스트 2 보유 골드/물약을 사용하고 구매를 저장한다.
- 저장 실패 시 구매 직전 골드와 수량으로 되돌린다.
- 마을에서 물약 사용/획득 시 보유 수량을 같은 저장에 반영한다.
- 기존 V2 저장에서 구매 방문 기록이 없으면 첫 방문 안내부터 시작한다.
- 프롤로그 진행 중 편의점에서는 기존 보급을 최소 5개로 유지한다.

검증
- 전체 변경 C++ 문법 검사 통과. 게임 빌드/실행은 하지 않았다.
- 물약 부족분 보충/초과 수량 유지, 구매 가격/잔액/99개 상한 테스트 통과.
- 빗맞음 여유 반경 및 벽 뒤 자동조준 제외 테스트 통과.
- 퀘스트 진행/보상 중복 방지, 새 리소스 로딩, 원본 SHA·메시 데이터 검증 통과.
- CPU 미리보기로 새 보스의 정면/후면/측면을 확인했다.
- 수동 확인: F3 골목에서 N 후 물약 5/5, Q 공격,
  F4의 B로 재시작 후 새 보스·변신·완료 → 편의점 E → 1/2 구매 → 재실행 수량 확인.
