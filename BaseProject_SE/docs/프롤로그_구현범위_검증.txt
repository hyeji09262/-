프롤로그 #4~#5 구현

기준: MagicalGirl_Md.md의 #4 프롤로그와 #5 학교 이벤트.
기존 OpenGL / 쿼터뷰 / Actor / SceneGraph / 배치 렌더러를 유지한다.
Unreal 전환이나 #6 메인 퀘스트, 변신, 전투, 신규 성장 시스템은 포함하지 않는다.

진행
1. 교복을 입은 평범한 학생으로 방에서 시작한다.
2. TV의 학생 실종 뉴스가 잠시 표시된다. TV 앞에서 E로 확인한다.
3. 뉴스 대화를 마치면 현관에서 E로 등교한다.
4. 벚꽃길을 따라 별빛 학교 앞 유나에게 이동한다.
5. E로 유나와 대화한다. 학교 학생의 마지막 목격 장소가 뒤편 골목이라는 소문을 듣는다.
6. 수업 시간 경과 연출 후 방과 후로 전환한다. 여기서 범위가 끝난다.

조작
WASD: 화면 방향 기준 이동 / R 누름: 달리기 / Space: 점프
E: 상호작용, 대화 다음 / 방향키: 카메라 둘러보기 / C: 카메라 복귀
ESC: 일시정지 / N: 일시정지 또는 완료 화면에서 프롤로그 초기화
F1: 기존 튜토리얼 / F2: 기존 사냥 레벨 / F4: 프롤로그
장면 전환 후 ESC로 계속한다. 전환 전 입력은 해제한다.
기존 튜토리얼과 사냥 레벨의 공격 키와 동작은 변경하지 않는다.
프롤로그에서는 아직 변신하지 않았으므로 공격/피해/마나 소비가 없다.

저장 및 성능
프롤로그 진행은 실행 중 장면을 바꿔도 유지되지만 프로그램 종료 시 저장하지 않는다.
기존 사냥 성장 저장 형식은 변경하지 않는다.
학생의 정지/걷기 모델을 primitive_models_v6.bin에 캐싱한다.
이전 v5 캐시는 삭제하지 않는다. 첫 실행에 v6를 생성하고 이후 읽는다.
지형/가구 Actor는 지역 전환 시에만 생성하고 유지한다. 화면 밖은 정렬 전에 제외한다.
cpu.prologue.update_ms, cpu.prologue.draw_ms, cpu.prologue.static_scene_build_ms,
prologue.collision_checks, prologue.dialogue_advance, prologue.story_step를 기록한다.
기존 draw call/FPS/GPU 프로파일링에도 프롤로그 장면이 포함된다.

사용자 수동 확인 (작성 시 게임 빌드/실행 및 테스트 실행은 하지 않음)
- 새 실행 시 방에서 시작하고 학생에게 마법봉이 없는지.
- WASD/대각 이동, R 달리기, 점프 착지, 가구/맵 경계 충돌이 정상인지.
- 방향키로 시점을 살펴보고 C로 복귀하는지.
- 뉴스 확인 전 현관에서 나가지 못하고 E를 떼고 누를 때 대화가 한 줄씩 진행되는지.
- 등굣길에서 학교까지 막힘 없이 이동할 수 있는지.
- 유나 가까이에서만 대화가 시작되고 실종/골목 소문이 표시되는지.
- 대화 중 이동이 멈추고 종료 후 방과 후 연출과 완료 안내가 나오는지.
- F1/F2 기존 레벨의 조작/공격이 유지되고 F4 복귀 시 진행이 남아 있는지.
- 전환/일시정지 중 키를 떼어도 이동이나 카메라가 고정 입력되지 않는지.
- N으로 프롤로그만 초기화되고 사냥 성장 값은 유지되는지.
- 창 크기를 바꿔도 UI, 목표, 캐릭터가 보이는지.
- tests/PrologueStoryTests.cpp는 별도 CPU 테스트로 순서/중복 대화/완료 고정을 검증한다.
