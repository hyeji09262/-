메인 퀘스트 1: 연락이 끊긴 친구

프롤로그 #5 방과 후에 자동으로 이어진다. 기존 F1 튜토리얼과 F2 사냥은 유지한다.
F4는 프롤로그/메인 스토리로 돌아간다. 장면 전환 후 ESC로 계속한다.

진행
지수 대화 → 경비원 → 편의점 직원 → 골목 입구 E → 검은 조각 E → 유나의 가방 E
→ 쓰러진 유나 E → 입구 방향으로 도주 → 루미 E → 첫 변신(3초)
→ 그림자 3마리 → 그림자 포식자 → 유나 확인 → 루미 보고 → 완료 보상
대화는 E로 열고 다시 E로 확인할 때 진행된다. 미래 단계 대상은 진행시킬 수 없다.
완료 보상: 변신/마법, 검은 조각 +3, 경험치 120, 골드 100.
앞서 조사한 조각 1개를 포함해 최종 검은 조각은 4개다. 보상은 한 번만 지급한다.
기존 Rpg::Progress의 경험치/스탯 공식을 재사용한다. 전투 도중 반복 사냥 보상은 없다.
후속 #18 종료 장면은 프롤로그18_종료장면.txt를 참고한다.
마지막 대사 확인 후 MQ_002_SOMETHING_IN_SCHOOL이 활성화되며 #19 플레이 내용은 미구현이다.

조작
WASD 이동 / Shift 누르기 달리기 / E 조사·대화 / 방향키 카메라 / C 카메라 복귀
Space 점프(변신 전후 동일). 변신 후 Q 기본 공격(3타 강화), R 재충전, Z 물약, 1 광역 마법.
광역 마법 MP 10, 마나 자동 회복. 회피 동작과 회피 무적은 제거했다.
Z 물약: 메인 퀘스트 중 변신 전후 사용 가능. 1개를 소비해 최대 체력의 45%를 회복한다.
체력이 가득 찼거나 사망/대화/일시정지/변신 연출 중이면 소비하지 않는다.
기존 사냥 레벨의 물약도 Q에서 Z로 변경했다. 피격 직후의 연속 피해 방지는 유지한다.
최신 공통 키 및 재충전 규칙은 공통_조작키.txt를 참고한다.
ESC 일시정지. 사망 또는 일시정지 중 N은 현재 퀘스트 단계부터 재도전한다.
아직 메인 퀘스트 시작 전이면 N은 기존처럼 프롤로그를 초기화한다.
R 달리기는 제거했다. 기존 사냥/튜토리얼의 공격·메뉴 키는 변경하지 않았다.

외형/바닥
주인공: 짙은 긴 머리와 교복. 유나: 갈색 포니테일과 분홍 리본.
지수: 단발/안경/녹색 가디건. 경비원: 큰 체형/제복/모자.
편의점 직원: 노란 셔츠/녹색 앞치마. 루미: 작은 흰 마법 생명체와 날개.
그림자 포식자: 큰 뿔, 붉은 눈, 이빨과 발톱. 모델 캐시는 v7로 분리한다.
프롤로그의 바닥 틈과 칸별 색 변화를 제거하고 기존 레벨의 칸별 색 차이/길 돌무늬도 줄였다.
충돌과 지도 데이터의 타일 구조는 유지한다. 지형 경계와 해안은 그대로다.

저장
%LOCALAPPDATA%\Emberwick\main_quest_001.txt 에 단계가 넘어갈 때 체크포인트 저장.
시작한 퀘스트는 재실행 시 불러온다. 전투 중 종료 시 현재 전투 단계를 처음부터 재개한다.
좌표/남은 HP/투사체/전투 중 처치 수는 저장하지 않는다. 조사/완료 단계와 보상은 유지한다.
기존 level1_progress.txt와 별개다. 서로의 성장 데이터를 덮어쓰지 않는다.
저장 실패는 HUD로 알리고 플레이는 계속한다. 손상/범위 밖 데이터는 불러오지 않는다.
저장 형식 V2는 남은 물약 수를 추가 저장하며 사용 직후 저장한다.
V1 저장도 불러올 수 있으며 저장되지 않았던 물약 수는 기본 3개로 시작한다.
단계 전환/재도전 시 물약을 다시 지급하지 않는다.

성능
Actor/SceneGraph 배치, 정적 지형 유지, 정렬 전 컬링, 모델 캐시 및 셰이더 효과 재사용.
cpu.quest.story_update_ms / cpu.quest.combat_update_ms / cpu.quest.actor_sync_ms
cpu.storage.main_quest_load_ms / cpu.storage.main_quest_save_ms
quest.step_entered / quest.enemy_deaths / quest.projectiles_alive
실제 프레임 개선 수치는 실행 측정 전에는 확정하지 않는다.

수동 검증 (게임 빌드/실행은 사용자 담당)
1. #5 이후 지수부터 순서대로 단서 조사와 골목 진입이 가능한가.
2. 이동 시작 전/이동 중 Shift를 누르거나 떼도 속도가 즉시 바뀌는가.
3. 인물 실루엣과 이름이 구분되고 바닥 격자 틈이 사라졌는가.
4. 변신 전 공격/마법이 잠기고, 도주 및 첫 변신이 정상 진행되는가.
5. Z 물약이 1개씩 소비되고 최대 체력을 초과하지 않으며 Z 돌진/무적이 사라졌는가.
6. 보스의 할퀴기/돌진/점프 예고를 보고 일반 이동으로 피한 후 공격할 틈이 있는가.
7. 사망 후 N으로 현재 전투를 다시 시작하고 완료한 조사 단계는 유지되는가.
8. 단계별 종료/재실행, 대화 반복, 완료 후 재접속에도 보상이 중복되지 않는가.
9. F1/F2의 기존 이동·공격·저장 데이터가 유지되는가.
10. tests/MainQuestTests.cpp를 별도 실행해 단계 순서/중복 처치/보상/전투 잠금을 확인한다.
