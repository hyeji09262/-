HUD 개선

프롤로그/메인 퀘스트: 상단 목표 노란색, 체력/마나 막대, 물약/조각 수량 표시.
전투 가능 시 우측에 마법봉 잔탄 6칸, 잔탄 숫자, 재충전 진행도를 표시한다.
비전투 학생 상태에서는 공격 안내와 마법봉 패널을 숨긴다.
대화창은 화자 영역, 본문, E 진행 안내를 분리한다.
하단은 두 줄 조작 안내로 정리하고 기존 키는 변경하지 않는다.
튜토리얼은 목표 노란색, 5칸 체력, 6칸 잔탄 표시를 적용한다.
사냥터는 기존 수치/경험치 표시를 유지하며 체력/마나 막대와 잔탄 6칸을 추가한다.
HUD는 기존 SceneGraph의 UI Actor에서 그린다. 별도 정렬이나 개별 flush를 추가하지 않는다.
새 스토리 HUD 비용은 cpu.story.hud_ms로 기록한다.

수동 확인 (게임 빌드/실행은 사용자 진행)
1. F1/F2/F3 전환 후 ESC로 재개하고 상단/하단 글자 겹침을 확인한다.
2. F3 목표와 화면 내 목표 표지가 노란색인지 확인한다.
3. Q로 잔탄이 감소하고 R로 재충전한 뒤 6칸이 채워지는지 확인한다.
4. 피격/회복/Z 물약/1 마법 사용 시 체력, 마나, 물약 수량이 일치하는지 확인한다.
5. E 대화, 긴 대사, #18 종료 장면과 일시정지 메뉴를 확인한다.
6. 1280x800 및 사용하는 창 크기에서 가독성을 확인한다.
7. Release 성능 로그로 HUD 비용과 draw call을 비교한다. 성능 개선을 측정한 것은 아니다.
